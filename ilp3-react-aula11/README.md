# 🚀 Single Page Applications (SPA) — Vue.js & React

Projeto prático desenvolvido durante a disciplina de **Linguagens de Programação III (ILP3)** no curso de **Informática para Negócios** da **FATEC São Bernardo do Campo (FATEC SBC)**.

O objetivo deste repositório é documentar a evolução prática na construção de aplicações front-end modernas, aplicando padrões de arquitetura de mercado, componentização e consumo de APIs utilizando os dois maiores frameworks do mercado: **Vue.js 3** e **React**.

---

## 🛠️ Tecnologias Utilizadas

### Módulo 1: Vue.js
* **Vue.js 3** (Options API & Composition API `setup`)
* **Vue Router 4** (Roteamento dinâmico e navegação)
* **Pinia** (Gerenciamento de estado global centralizado)
* **Axios** (Cliente HTTP para consumo de API REST)

### Módulo 2: React
* **React 18** (Componentes Funcionais & Hooks)
* **JSX** (JavaScript XML)

### Ferramentas Base
* **Vite** (Build tool e servidor de desenvolvimento ultrarrápido)
* **JavaScript (ES6+)**, **HTML5** e **CSS3**
* **IDE:** JetBrains IntelliJ IDEA

---

## 📈 Evolução das Aulas (Roadmap do Semestre)

### 🟢 Módulo Vue.js (Concluído)
- [x] **Aulas 01 a 03 — Fundamentos:** Estrutura de Single File Components (`.vue`), interpolação, diretivas e reatividade básica.
- [x] **Aula 04 — Eventos:** Comunicação Filho → Pai utilizando `$emit`, *props* e fluxo de dados unidirecional.
- [x] **Aula 05 — Computed & Watchers:** Cálculos derivados com cache (`computed`) e monitoramento de efeitos colaterais (`watch`).
- [x] **Aula 06 — Ciclo de Vida (Lifecycle Hooks):** Controle de execução com `created`, `mounted`, `updated` e limpeza de recursos (`unmounted`).
- [x] **Aula 07 — Vue Router:** Estruturação de SPA, parâmetros dinâmicos via URL (`/usuarios/:id`), e tratamento de erro 404.
- [x] **Aula 08 — Consumo de API (Axios):** Integração com REST API pública, requisições assíncronas (`async/await`) e *loading states*.
- [x] **Aula 09 — Estado Global (Pinia):** Centralização de dados globais em *Stores* (`state`, `getters` e `actions`), eliminando *prop drilling*.
- [x] **Aula 10 — Mini Projeto CRUD Completo:** Integração geral (Criar, Listar, Visualizar, Editar e Excluir) com geração sequencial de IDs e arquitetura profissional de mercado.
